# Анализ видео по ТЗ (проекты 86-87, 88-89)

Правила разметки и разбор ТЗ — `docs/TZ_analysis.md`. Читать перед любой оценкой видео.

## Как анализировать видео

```bash
pip install -r requirements.txt
python -m video_analyzer path/or/url.mp4 [ещё видео...] --out out   # вердикт + раскадровка
python -m video_analyzer.calibrate                                   # прогон по 17 примерам из ТЗ
python -m pytest tests -q                                            # синтетические тесты
```

1. Запустить анализатор — он ловит: короткое видео, рамки/поля, пересвет, полный блюр > 1 c,
   низкую комплексность, блочность, статичные вотермарки/логотипы.
2. **Обязательно** открыть `out/<имя>_sheet.jpg` и `out/<имя>_frame*.jpg` через Read и пройти
   визуальный чек-лист из отчёта (субтитры и сменяющийся текст, отзеркаливание, эффект плёнки,
   геометрия, размытый передний план, сюжет, нейросеть). Автоматика это не решает.
3. Итог выдавать в формате кнопок ТЗ: «Отправить» или «Плохое кадрирование/артефакт» +
   список артефактов формулировками из таблицы ТЗ. В спорных случаях — «Отправить».

Пороги эвристик — `AnalysisConfig` в `video_analyzer/analyzer.py`. Менять только после
прогона `calibrate` на примерах из ТЗ (`video_analyzer/tz_examples.json`).
